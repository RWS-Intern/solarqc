# SolarQC — Pilot Briefing

Thanks for helping pilot SolarQC. A few honest notes before you start:

## What this is

This is genuinely new software, being piloted with just one or two people right now. It has been tested end-to-end against the live app, but a small pilot is exactly how the remaining rough edges get found. If anything feels off, confusing, or wrong — even something small — please say so. That feedback is the point of this phase.

## Known limitations

- **Approvers can't sign off offline.** The approval step needs a live connection at the moment the verdict is submitted. If you're an approver working somewhere with unreliable signal, plan to review and submit from a spot with a stable connection.
- **Non-Latin-script names on certificates.** If a customer's name uses a script the certificate font doesn't support (e.g. Devanagari, Arabic), each unsupported character currently renders as `?` on the generated PDF certificate. The rest of the certificate is unaffected. This is a known gap, not a bug specific to your job.

## If something goes wrong

Errors that happen while you're signed in are logged automatically and are visible to the admin (Error Logs page). You don't need to screenshot every glitch — but if something stops you from finishing a job, or a page looks broken, let us know what you were doing when it happened.

## Getting started

You'll receive a sign-in email/invite separately. If you don't get one, or your password reset doesn't arrive, ask rather than waiting.
